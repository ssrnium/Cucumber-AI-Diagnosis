### 本机无 Docker 启动手册（全部实测）

```bash
# 依赖件（tools/ 下，便携）：JDK17、Maven 3.9.9、PG 16.10、Redis 5.0.14、Playwright
# 1) PostgreSQL —— 必须经 pg_ctl 启动（postgres.exe 直连被管理员权限拒绝）；
#    且必须用 nohup ... & disown 方式拉起，否则进程随命令回收
nohup $HOME/pgsql16/bin/pg_ctl.exe -D $HOME/pgdata \
  -l $HOME/pgdata/server.log -w -t 60 start >/dev/null 2>&1 & disown
# 2) Redis（前台进程型，用后台任务/nohup 均可）
$PROJECT_ROOT/tools/redis/redis-server.exe --port 6379 --bind 127.0.0.1

cd cucumber-ai && PYTHONUTF8=1 .venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## 5. 关键坑位清单（全部是真实踩过并修复的，面试可直接讲）

1. **PostgreSQL jsonb 写入 500**：MyBatis-Plus JacksonTypeHandler 以 varchar 传参被 PG 拒 → JDBC URL `stringtype=unspecified`（主链路此前从未真跑通过，验收才抓到）；
2. **Jackson 命名不一致**：后端 camelCase vs 前端 snake_case 导致记录页/复核页/来源弹窗全空 → 全局 `SNAKE_CASE` + 前端一处 `imageUrl→image_url`；
3. **思考型 LLM 的 token 预算**：deepseek-flash 默认输出 thinking 块，EchoMind 7 处 max_tokens 256~512 被思考吃光无输出 → 上调至 1024/1600；
4. **Kimi k3 首润丢 protected 字段**：与论文首过率 15% 同现象 → 纠错重润机制天然兜住，但端到端 40-50s → admin 读超时 30→150s；
5. **系统代理劫持本地请求**：httpx/openai SDK 默认 trust_env=True 走代理 → Connection error 间歇发作 → `trust_env=False`（论文同款）；
6. **Windows 进程回收**：前台 Bash 命令结束后其子进程被回收 → PG/服务反复"神秘消失" → nohup+disown 或长驻后台任务；**TaskStop 会连坐杀整树**（PG 两次被误杀）；
7. **PG 权限与启动**：postgres.exe 拒绝管理员权限用户，必须 pg_ctl；`pg_ctl -W` 立即返回防挂死；
8. **netstat/taskkill 在 Windows Python 下**：`//PID` 是 Git Bash 专用，Python 里必须 `/PID`；netstat 输出 GBK 需 errors="ignore"；
9. **vite 只绑 ::1**：127.0.0.1 拒绝而 localhost 通——验收脚本统一用 localhost；
10. **去重副作用**：内容哈希去重命中时不产生新推理 → 耗时字段为空（正确语义，文档已注明）。
