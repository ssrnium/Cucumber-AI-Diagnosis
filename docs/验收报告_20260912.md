## 1. 项目架构与调用链

```
浏览器 cucumber-web (5173, vite dev)
  │  /api/**、/files/** 代理
  ▼
cucumber-admin (8080, Spring Boot 3.3.4) ──► PostgreSQL 16.10 (5432, 业务库 cucumber_db)
  │  ├── AiServiceClient ──► cucumber-ai (8000, FastAPI：/detect + /diagnose + /knowledge/{sid} + /eval/run)
  │  ├── AgentServiceClient ──► cucumber-agent (8002, EchoMind 多 Agent 编排)
  │  ├── Redis (6379，声明待用)
  │  └── RabbitMQ（默认关闭，mq.enabled=false 走同步诊断；compose 中为 true）
  ▼
cucumber-agent ──tools──► cucumber-ai（diagnose_image）/ cucumber-admin（svc-agent：查记录、建反馈）
             └─ Chroma（嵌入式知识库，28 条种子）/ DeepSeek（Anthropic 协议，deepseek-flash）
```

诊断主链路（本地同步模式）：
`登录 → POST /api/v1/diagnosis(multipart) → 内容哈希去重 → 存文件 → AI /detect → AI /diagnose → jsonb 落库(status=DONE) → 前端病斑框+报告+来源 → 记录/反馈/复核/日志`

智能体链路：`web 对话页 → admin /api/v1/agent/chat（代理+审计+user_id 透传）→ agent 意图识别→角色路由→工具调用→回复 → agent_session/agent_message 落库`
