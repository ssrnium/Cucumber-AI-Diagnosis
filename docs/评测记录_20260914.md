## 诚实解读（不美化）

1. **意图识别是强项**：三路融合（LLM 70% + 模板向量 20% + 关键词 10%）在六类农业意图上全部命中，且每条预测附置信度（0.74-0.97）与 reasoning——面试可现场展示 `eval_run_20260914.json` 的 per-case 明细；
2. **对话质量中等**：Judge 扣分集中在"回答偏简、操作步骤不完整"（推荐项也指向同一处）——当前各领域 Agent 的 system prompt 偏"简洁克制"，导致答案完整度不足；这不是链路问题，是 prompt 调优空间（已列入后续规划，不动秋招版范围）；
3. **用药安全性 0.667 需盯**：Judge 对药剂建议的"安全间隔期/禁忌提示"覆盖度扣分——用药 Skill 里已有合规边界要求，但模型执行不稳定，这正是我们把"用药建议必须有安全间隔期"写进 SOP 的原因（后续可复查对比）；
4. 数字口径说明：对话通过率 0.5 的分母为 4（3 条对话 + 意图测试合并计 1 项）；除意图 100% 外，其余分数来自 LLM-as-Judge（同一 deepseek-flash 模型，固定 prompt 六维打分），只代表该 Judge 口径下的相对水平。
